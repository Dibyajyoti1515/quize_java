+4.00 Pts Awarded • schedule 1m 34s duration

In the Raft distributed consensus protocol, which prerequisite invariant must be met before a candidate node can successfully transition into a cluster leader for a new term?

A
The candidate must have received commit acknowledgments from all nodes participating in the cluster across all preceding terms.
check
Option B • Your Answer (Correct) Key Answer
The candidate must receive votes from a strict majority (quorum) of servers for the term, and its log must be at least as up-to-date as any other node in that quorum.
C
The node must force an immediate heartbeat pulse and append a dummy no-op entry into its persistent state before collecting votes.
D
The candidate node must possess the lowest physical wall-clock timestamp skew relative to the network time protocol (NTP) master.
school Instructor Solution Commentary

Under Raft Section 5.2 and 5.4, leader election safety relies on the Election Safety Invariant and the Leader Completeness Property. A candidate only wins an election if it secures votes from a majority of servers:

votesCount ≥ ⌊N/2⌋ + 1 && (lastLogTerm_cand > lastLogTerm_voter || (lastLogTerm_cand == lastLogTerm_voter && lastLogIndex_cand ≥ lastLogIndex_voter))

This guarantees that any committed entry in any previous term is already stored on at least one server within the newly formed voting quorum.
